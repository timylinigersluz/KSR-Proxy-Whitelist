# KSR-Proxy-Whitelist

Ein Velocity-Plugin für Minecraft (ab Version 3.4), das den Proxy-Präfix  
(`Kein Verbindungsaufbau zu ... möglich:`) bei Whitelist-Kicks entfernt  
und stattdessen nur die Nachricht des Paper-Servers anzeigt.

---

## ✨ Features
- Entfernt unnötigen Proxy-Präfix bei Whitelist-Kicks
- Zeigt nur die vom Paper-Server gesetzte Kick-Nachricht
- Schlankes Proxy-Plugin ohne zusätzliche Abhängigkeiten

---

## ⚙️ Installation
1. Lade die neueste JAR-Datei aus dem [Releases](../../releases)-Bereich herunter.
2. Lege die JAR in den `plugins`-Ordner deines **Velocity-Proxys**.
3. Starte den Proxy neu.

---

## 📦 Build
Projekt basiert auf **Maven**.  
Zum Bauen einfach im Projektordner ausführen:

```bash
mvn clean package
```

Das fertige JAR findest du im Verzeichnis:
```
target/KSR-Proxy-Whitelist-1.0.0.jar
```
